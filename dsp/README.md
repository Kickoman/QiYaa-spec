# DSP reference vectors

JSON files generated by the desktop app and checked by the tests of both apps:

- equalizer frequency response: settings (flat, each built-in preset, ±12 dB extremes, preamp) ×
  sample rates 44 100 / 48 000 × frequencies → dB;
- dB ↔ `.eqf` values;
- the 19-band spectrum for sines at given frequencies.

Every file states the tolerance its values are compared with.

Filled by Kickoman/QiYaa#4.
